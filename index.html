🚀 Guía Rápida para Publicar y Conectar tu Cuenta de AdSense:

  1. Configura tu Publisher ID: Abre el archivo js/ads-config.js dentro de la carpeta del sitio que vayas a publicar. Cambia client: "ca-pub-XXXXXXXXXXXXXXXX" por tu ID real de AdSense y cambia enabled: false a enabled: true.
  2. Personaliza el dominio o correo si lo deseas: En el pie de página y páginas de contacto/legal puedes sustituir el correo por tu dirección personal.
  3. Sube los archivos a tu Hosting: Puedes subir cada carpeta directamente a tu servidor (cPanel, Nginx, Apache), o desplegarlos de forma 100% gratuita con soporte SSL en Cloudflare Pages, Netlify, Vercel o GitHub Pages.
  4. Solicita la revisión en AdSense: Añade la URL de tu sitio web en la consola de Google AdSense. El equipo de revisión verificará el contenido de calidad y la presencia de las políticas legales.
